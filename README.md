**Что живое в макете**
- Расписание занятий — из системы записи клуба (mobi.fitness).
- Прайс, тренеры, программы, описания — с parkfitness.biz.
- Отзывы — цитаты из карточек клуба в 2ГИС.
- Логотип и фото зала принадлежат клубу.

**Что доработается при разработке**
- Форма «Пробное занятие» — подключение к CRM/почте.
- Галочка согласия с обработкой персональных данных (152-ФЗ).
- Фото тренеров и зала в студийном качестве.
